
# Setting Up a Local Selenium Grid

Setting up a local Selenium Grid involves configuring a hub and one or more nodes to run your tests. The hub acts as the central point where tests are distributed to available nodes. Here’s how you can set it up using Docker, which simplifies the setup process:

## Step-by-Step Guide to Set Up a Local Selenium Grid

### Prerequisites:
1. **Docker**: Ensure Docker is installed on your machine. You can download and install Docker from [Docker's official website](https://www.docker.com/products/docker-desktop).

### Step 1: Pull the Docker Images
First, pull the necessary Docker images for the Selenium Grid hub and nodes.

```sh
docker pull selenium/hub
docker pull selenium/node-chrome
docker pull selenium/node-firefox
```

### Step 2: Start the Selenium Grid Hub
Run the Selenium Grid hub using Docker:

```sh
docker run -d -p 4444:4444 --name selenium-hub selenium/hub
```

This command will start a Selenium Grid hub and map port 4444 on your localhost to port 4444 in the Docker container.

### Step 3: Start the Selenium Grid Nodes
Start one or more nodes and link them to the hub. You can start nodes with different browsers (Chrome, Firefox) as needed.

For Chrome node:

```sh
docker run -d --link selenium-hub:hub selenium/node-chrome
```

For Firefox node:

```sh
docker run -d --link selenium-hub:hub selenium/node-firefox
```

These commands will start Selenium Grid nodes and link them to the hub. The `--link selenium-hub:hub` part ensures that the nodes are connected to the hub.

### Step 4: Verify the Setup
Open a browser and navigate to `http://localhost:4444/grid/console`. You should see the Selenium Grid console with the connected nodes listed.

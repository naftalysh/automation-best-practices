
# Setting Up a Local Selenium Grid

Setting up a local Selenium Grid involves configuring a hub and one or more nodes to run your tests. The hub acts as the central point where tests are distributed to available nodes. Here’s how you can set it up using Podman, which simplifies the setup process:

## Step-by-Step Guide to Set Up a Local Selenium Grid

### Prerequisites:
1. **Podman**: Ensure Podman is installed on your machine. You can download and install Podman from [Podman's official website](https://podman.io/getting-started/installation).

### Step 1: Pull the Podman Images
First, pull the necessary images for the Selenium Grid hub and nodes.

```sh
podman pull selenium/hub
podman pull selenium/node-chrome
podman pull selenium/node-firefox
```

### Step 2: Create a Podman Network
Create a network to ensure the containers can communicate with each other.

```sh
podman network create selenium-grid
```

### Step 3: Start the Selenium Grid Hub
Run the Selenium Grid hub using Podman and attach it to the network.

```sh
podman run -d --name selenium-hub --network selenium-grid -p 4444:4444 selenium/hub
```

### Step 4: Start the Selenium Grid Nodes
Start the Chrome nodes and attach them to the network with a network alias.

```sh
podman run -d --name node-chrome-1 --network selenium-grid --network-alias hub selenium/node-chrome
podman run -d --name node-chrome-2 --network selenium-grid --network-alias hub selenium/node-chrome
podman run -d --name node-chrome-3 --network selenium-grid --network-alias hub selenium/node-chrome

- Version 2
podman run -d --name node-chrome-1 --network selenium-grid --env SE_EVENT_BUS_HOST=selenium-hub --env SE_EVENT_BUS_PUBLISH_PORT=4442 --env SE_EVENT_BUS_SUBSCRIBE_PORT=4443 selenium/node-chrome
podman run -d --name node-chrome-2 --network selenium-grid --env SE_EVENT_BUS_HOST=selenium-hub --env SE_EVENT_BUS_PUBLISH_PORT=4442 --env SE_EVENT_BUS_SUBSCRIBE_PORT=4443 selenium/node-chrome
podman run -d --name node-chrome-3 --network selenium-grid --env SE_EVENT_BUS_HOST=selenium-hub --env SE_EVENT_BUS_PUBLISH_PORT=4442 --env SE_EVENT_BUS_SUBSCRIBE_PORT=4443 selenium/node-chrome

```

These commands will start three Chrome nodes and attach them to the Selenium hub network.

### Step 5: Verify the Setup
Open a browser and navigate to `http://localhost:4444/grid/console`. You should see the Selenium Grid console with the connected nodes listed.

### Uninstalling the Selenium Grid Elements

If you need to remove the Selenium Grid setup from your local environment, you can follow these steps:

1. **Stop and Remove the Selenium Grid Hub and Nodes**:
   ```sh
   podman stop selenium-hub node-chrome-1 node-chrome-2 node-chrome-3
   podman rm selenium-hub node-chrome-1 node-chrome-2 node-chrome-3
   ```

2. **Remove the Podman Network**:
   ```sh
   podman network rm selenium-grid
   ```

3. **Remove the Pulled Images**:
   ```sh
   podman rmi selenium/hub selenium/node-chrome selenium/node-firefox
   ```

These commands will stop and remove the Selenium Grid hub and node containers, delete the network, and remove the pulled images from your local environment.

### Force Removing Images in Use

If you encounter an error indicating that an image is in use by a container, follow these detailed steps to forcefully remove the images:

1. **List all containers**:
   ```sh
   podman ps -a
   ```

   This command lists all containers, including those that are stopped. Note the container IDs or names.

2. **Stop all running containers**:
   ```sh
   podman stop $(podman ps -a -q)
   ```

   This command stops all running containers.

3. **Remove all containers**:
   ```sh
   podman rm $(podman ps -a -q)
   ```

   This command removes all containers, both running and stopped.

4. **Force remove the images**:
   ```sh
   podman rmi -f selenium/hub selenium/node-chrome selenium/node-firefox
   ```

   This command forcefully removes the specified images.


# Setting Up a Local Selenium Grid

Setting up a local Selenium Grid involves configuring a hub and one or more nodes to run your tests. The hub acts as the central point where tests are distributed to available nodes. Here’s how you can set it up using Podman, which simplifies the setup process:

## Step-by-Step Guide to Set Up a Local Selenium Grid

### Prerequisites:
1. **Podman**: Ensure Podman is installed on your machine. You can download and install Podman from [Podman's official website](https://podman.io/getting-started/installation).

### Step 1: Pull the Podman Images
First, pull the necessary images for the Selenium Grid hub and nodes.

```sh
podman pull selenium/hub
podman pull selenium/node-chrome
podman pull selenium/node-firefox
```

### Step 2: Create a Podman Network
Create a network to ensure the containers can communicate with each other.

```sh
podman network create selenium-grid
```

### Step 3: Start the Selenium Grid Hub
Run the Selenium Grid hub using Podman and attach it to the network.

```sh
podman run -d --name selenium-hub --network selenium-grid -p 4444:4444 selenium/hub
```

### Step 4: Start the Selenium Grid Nodes
Start the Chrome nodes and attach them to the network with a network alias.

```sh
podman run -d --name node-chrome-1 --network selenium-grid --network-alias hub selenium/node-chrome
podman run -d --name node-chrome-2 --network selenium-grid --network-alias hub selenium/node-chrome
podman run -d --name node-chrome-3 --network selenium-grid --network-alias hub selenium/node-chrome
```

These commands will start three Chrome nodes and attach them to the Selenium hub network.

### Step 5: Verify the Setup
Open a browser and navigate to `http://localhost:4444/grid/console`. You should see the Selenium Grid console with the connected nodes listed.

### Uninstalling the Selenium Grid Elements

If you need to remove the Selenium Grid setup from your local environment, you can follow these steps:

1. **Stop and Remove the Selenium Grid Hub and Nodes**:
   ```sh
   podman stop selenium-hub node-chrome-1 node-chrome-2 node-chrome-3
   podman rm selenium-hub node-chrome-1 node-chrome-2 node-chrome-3
   ```

2. **Remove the Podman Network**:
   ```sh
   podman network rm selenium-grid
   ```

3. **Remove the Pulled Images**:
   ```sh
   podman rmi selenium/hub selenium/node-chrome selenium/node-firefox
   ```

These commands will stop and remove the Selenium Grid hub and node containers, delete the network, and remove the pulled images from your local environment.

### Troubleshooting Node Registration

If the nodes are not registering with the hub, follow these steps to troubleshoot and fix the issue:

1. **Verify Network Configuration**:
   Ensure that the `selenium-grid` network exists.
   ```sh
   podman network ls
   ```

   If the network does not exist, create it:
   ```sh
   podman network create selenium-grid
   ```

2. **Start the Selenium Grid Hub**:
   Make sure the hub is started and attached to the `selenium-grid` network.
   ```sh
   podman run -d --name selenium-hub --network selenium-grid -p 4444:4444 selenium/hub
   ```

3. **Start the Selenium Grid Nodes**:
   Start the Chrome nodes and attach them to the network with the necessary environment variables.
   ```sh
   podman run -d --name node-chrome-1 --network selenium-grid --env SE_EVENT_BUS_HOST=selenium-hub --env SE_EVENT_BUS_PUBLISH_PORT=4442 --env SE_EVENT_BUS_SUBSCRIBE_PORT=4443 selenium/node-chrome
   podman run -d --name node-chrome-2 --network selenium-grid --env SE_EVENT_BUS_HOST=selenium-hub --env SE_EVENT_BUS_PUBLISH_PORT=4442 --env SE_EVENT_BUS_SUBSCRIBE_PORT=4443 selenium/node-chrome
   podman run -d --name node-chrome-3 --network selenium-grid --env SE_EVENT_BUS_HOST=selenium-hub --env SE_EVENT_BUS_PUBLISH_PORT=4442 --env SE_EVENT_BUS_SUBSCRIBE_PORT=4443 selenium/node-chrome
   ```

4. **Check Node Logs**:
   Check the logs of the node containers to ensure they are attempting to register with the hub and identify any errors.
   ```sh
   podman logs node-chrome-1
   podman logs node-chrome-2
   podman logs node-chrome-3
   ```

### Force Removing Images in Use

If you encounter an error indicating that an image is in use by a container, follow these detailed steps to forcefully remove the images:

1. **List all containers**:
   ```sh
   podman ps -a
   ```

   This command lists all containers, including those that are stopped. Note the container IDs or names.

2. **Stop all running containers**:
   ```sh
   podman stop $(podman ps -a -q)
   ```

   This command stops all running containers.

3. **Remove all containers**:
   ```sh
   podman rm $(podman ps -a -q)
   ```

   This command removes all containers, both running and stopped.

4. **Force remove the images**:
   ```sh
   podman rmi -f selenium/hub selenium/node-chrome selenium/node-firefox
   ```

   This command forcefully removes the specified images.

### Integrate Allure Reporting

To generate and view Allure reports, follow these steps:

1. **Install Allure Pytest Plugin**:
   ```sh
   pip install allure-pytest
   ```

2. **Install Allure Command Line Tool**:
   - Visit the [Allure Framework download page](https://github.com/allure-framework/allure2/releases).
   - Download the appropriate version for your operating system. For example, you can download the zip file for Windows.
   - Extract the downloaded file to a preferred location on your machine.
   - Add the `bin` directory of the extracted folder to your system's PATH environment variable. This allows you to run Allure commands from any directory in your command line.

   **For Windows**:
   - Open the Start Menu and search for "Environment Variables".
   - Select "Edit the system environment variables".
   - In the System Properties window, click on the "Environment Variables" button.
   - In the Environment Variables window, find the "Path" variable in the "System variables" section and click "Edit".
   - Click "New" and add the path to the `bin` directory of the extracted Allure folder.
   - Click "OK" to save the changes.

   **For macOS/Linux**:
   - Open your terminal.
   - Add the following line to your `~/.bashrc`, `~/.zshrc`, or `~/.profile` file, depending on your shell:
     ```sh
     export PATH=$PATH:/path/to/allure/bin
     ```
   - Replace `/path/to/allure/bin` with the actual path to the `bin` directory of the extracted Allure folder.
   - Save the file and run `source ~/.bashrc` or `source ~/.zshrc` to apply the changes.

3. **Verify Installation**:
   - Open a new terminal or command prompt and run:
     ```sh
     allure --version
     ```
   - This command should output the version of Allure, indicating that it is installed correctly.

### Installing Java and Setting JAVA_HOME

To generate and view Allure reports, you need to have Java installed on your machine. Follow these steps:

1. **Download and Install Java**:
   - Visit the [Oracle Java SE Downloads page](https://www.oracle.com/java/technologies/javase-downloads.html) or the [OpenJDK Downloads page](https://jdk.java.net/).
   - Download the appropriate version for your operating system.
   - Follow the installation instructions.

2. **Set JAVA_HOME Environment Variable**:

   **For Windows**:
   - Open the Start Menu and search for "Environment Variables".
   - Select "Edit the system environment variables".
   - In the System Properties window, click on the "Environment Variables" button.
   - In the Environment Variables window, click "New" under the "System variables" section.
   - Set the variable name as `JAVA_HOME` and the variable value as the path to your Java installation (e.g., `C:\Program Files\Java\jdk-11.0.11`).
   - Find the "Path" variable in the "System variables" section and click "Edit".
   - Click "New" and add `%JAVA_HOME%in`.
   - Click "OK" to save the changes.

   **For macOS/Linux**:
   - Open your terminal.
   - Add the following lines to your `~/.bashrc`, `~/.zshrc`, or `~/.profile` file, depending on your shell:
     ```sh
     export JAVA_HOME=/path/to/java
     export PATH=$JAVA_HOME/bin:$PATH
     ```
   - Replace `/path/to/java` with the actual path to your Java installation.
   - Save the file and run `source ~/.bashrc` or `source ~/.zshrc` to apply the changes.

3. **Verify Java Installation**:
   - Open a new terminal or command prompt and run:
     ```sh
     java -version
     ```
   - This command should output the version of Java, indicating that it is installed correctly.

4. **Verify Allure Installation**:
   - After setting `JAVA_HOME`, verify Allure installation again:
     ```sh
     allure --version
     ```
   - This command should output the version of Allure, indicating that it is installed correctly.

### Using a Portable Version of Java

To avoid a full Java installation, you can use a portable version of Java:

1. **Download a Portable Version of Java**:
   - Visit [Zulu OpenJDK](https://www.azul.com/downloads/?package=jdk) and select the version suitable for your operating system.
   - Choose the `.zip` package to download a portable version.

2. **Extract the Portable Java**:
   - Extract the downloaded `.zip file to a preferred location on your machine.

3. **Set `JAVA_HOME` to the Extracted Directory**:
   - Set the `JAVA_HOME` environment variable to point to the directory where you extracted the portable Java.
   - Add the `bin` directory of this portable Java to your system's PATH environment variable.

**For Windows**:

1. **Download and Extract**:
   - Download the portable version from [Zulu OpenJDK](https://www.azul.com/downloads/?package=jdk).
   - Extract it to a location, e.g., `C:\PortableJava\`.

2. **Set Environment Variables**:
   - Open the Start Menu and search for "Environment Variables".
   - Select "Edit the system environment variables".
   - In the System Properties window, click on the "Environment Variables" button.
   - In the Environment Variables window, click "New" under the "System variables" section.
   - Set the variable name as `JAVA_HOME` and the variable value as the path to your portable Java directory (e.g., `C:\PortableJava\zulu11.50.19-ca-jdk11.0.11-win_x64`).
   - Find the "Path" variable in the "System variables" section and click "Edit".
   - Click "New" and add `%JAVA_HOME%in`.
   - Click "OK" to save the changes.

**For macOS/Linux**:

1. **Download and Extract**:
   - Download the portable version from [Zulu OpenJDK](https://www.azul.com/downloads/?package=jdk).
   - Extract it to a location, e.g., `/opt/PortableJava/`.

2. **Set Environment Variables**:
   - Open your terminal.
   - Add the following lines to your `~/.bashrc`, `~/.zshrc`, or `~/.profile` file, depending on your shell:
     ```sh
     export JAVA_HOME=/opt/PortableJava/zulu11.50.19-ca-jdk11.0.11-linux_x64
     export PATH=$JAVA_HOME/bin:$PATH
     ```
   - Replace the path with the actual path to your extracted portable Java directory.
   - Save the file and run `source ~/.bashrc` or `source ~/.zshrc` to apply the changes.
